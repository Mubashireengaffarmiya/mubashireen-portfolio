# 🤖 MUBA AI

## Mubashireen's Personal AI Assistant

A major feature of this portfolio is **MUBA AI**, a voice-first personal AI assistant.

The visual identity of the assistant is a circular:

**M**

The **M** represents **MUBASHIREEN**.

MUBA AI is designed as a voice assistant rather than a traditional text chatbot.

---

# 🎙️ Voice-First AI Experience

The main interaction follows:

CLICK M → GREETING → WAIT → USER SPEAKS → LISTEN → THINK → SPEAK → STOP → WAIT

When activated, MUBA AI introduces itself by voice:

> "Hi, I am Mubashireen's Personal AI Assistant. Ask me about Mubashireen."

After the greeting, MUBA AI stops speaking and waits for the visitor.

The user then speaks naturally, and MUBA AI listens, processes the question, and responds by voice.

---

# 🌊 MUBA AI Visual States

The circular M acts as the main AI interface.

- Animated sound waves

# 🗣️ Voice Interaction

MUBA AI is designed to support:

- Speech Recognition
- Voice Activity Detection
- Silence Detection
- Text-to-Speech
- Natural voice responses
- Interruptible speech
- Microphone permission handling
- Voice state visualization

The user does not need a traditional chat interface.

The main interaction is through voice.

---

# 🛑 Natural Waiting Behavior

After the initial greeting:

MUBA AI stops.

It waits for the user.

After answering a question:

MUBA AI stops again.

It does not:

- Keep talking
- Ask unnecessary questions
- Generate automatic follow-up questions
- Continue speaking without user interaction

The user initiates the next interaction.

---

# 🔊 Interruptible Speech

If MUBA AI is speaking and the user starts speaking:

MUBA AI should stop its current speech and switch to listening.

This creates a more natural conversational experience.

# SIH26034

## Software System to check compliance of Packaged Commodities under Legal Metrology Rules, 2011

### GitHub Repository
https://github.com/Mubashireengaffarmiya/SIH_PROJECT

SIH26034 is the main featured project in my portfolio.

The project is designed as a software system for AI/OCR-assisted screening of packaged commodity labels/images against configured compliance rules.

---

# 🎯 SIH Project Problem

Checking packaged commodity labels for relevant declarations can require reviewing multiple pieces of information.

The project aims to assist this process through software-assisted image analysis and rule-based screening.

---
